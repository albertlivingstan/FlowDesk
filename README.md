# FlowDesk 3.0 · Intelligence Command Center (React SPA)

FlowDesk is an intelligence command center and service operations platform for automated ticket triage, routing, research analytics, and robot simulation.

## Features
- **Intelligence Overview**: Operational pulse KPIs, incoming vs completed volume trends, status distribution ring, department workload bars, and SLA risk explorer.
- **Ticket Management**: Searchable queue, multi-criteria filtering, pagination, ticket details drawer with audit trail and internal notes.
- **Research Analytics**: Hourly arrival heat profile, category mix, priority distribution, and research integrity notes.
- **Automation Lab**: Realistic ticket creation sandbox with rule-based classification and routing.
- **Data Export**: CSV ticket export and persistent client-side storage.

## Tech Stack
- React 18 with TypeScript
- Vite
- Custom CSS design system matching FlowDesk 3.0 UI specifications
